# CosmoLog Player Guide

Help Nova investigate the fictional evil.esAI incident. Follow people and conversations, preserve original evidence, and explain your findings.

The recommended student workstation is Parrot Security OS with the required tools already installed; Kali Linux is the alternative. The organizer supplies the prepared VM or app address.

## Getting started

Use the app address supplied by your organizer. Sign in with the assigned student account. Two people using the same account on one instance share progress. Ask the organizer which instance and account belong to your team.

## Navigate the community

Home shows community posts; Following narrows the feed to accounts you follow. Explore searches topics and accounts. Open replies and original attachments to check context. Messages and Notifications provide conversations and follow-ups. Bookmarks keep useful source links together.

Case files provides original evidence, file sizes, and SHA-256 hashes. Mission journal groups Core, Forensics, Side stories, and Final. Read hints progressively. Station tools supports the web exercises. Operations console connects the earlier learning in a final review.

## Work with evidence

Save original downloads separately from working copies. Compare each file hash against Case files and note your source. Record the tool, analysis steps, relevant result, alternative explanation, and conclusion. A familiar filename or alarming phrase is a lead, not proof.

The seven forensic cases use supplied offline files. Use the tools prepared by the organizer; no live network capture or connection to evidence-only addresses is required. Read acquisition notes before opening or extracting evidence.

## Completion

There are 15 numbered challenges plus four optional side stories. The seven original web challenges total 1,550 points. The forensic sequence and final review record completion separately. Use the AstroSec{} flag format and submit to the matching entry. Duplicate submissions do not add points.

The final review requires observed request behavior and a supported finding. Use your evidence notebook to explain what runs, what input matters, and how the proposed fix changes the result.

## Session behavior

Progress follows your current account and resets if the server restarts. Record your explanation and ask the organizer before changing session identity or leaving a session. Use only the assigned lab and follow the event scope and help procedure.
