## Open the staff vault

The staff vault is distributed privately, not through this repository. It has no username and no relationship to the app accounts.

1. Download the HTML vault and the separately supplied Unlock Key file to a trusted organizer device.
2. Save the HTML file locally. A cloud preview may display source text or disable scripts; it is not the unlock interface.
3. Open the saved HTML in a current web browser.
4. Open the Unlock Key text file separately and locate its Passphrase section.
5. Enter that passphrase in the vault and choose Verify and unlock.
6. After successful verification, download the staff ZIP and extract it outside the lab checkout.
7. Lock/close the vault after use. Protect or remove any downloaded plaintext copies separately.

The private package contains the current Word Setup and Learning Guide, Hint Book, Staff Guide, and technical reference. A wrong key or altered vault is rejected. If the key is lost, request a replacement package from the organizer; the encrypted copy does not contain a password recovery mechanism.

Do not put the key in an Issue, Discussion, wiki page, screenshot, VM image, GitHub commit, or the vulnerable application. Keep the vault and key separately. Closing the browser cannot erase a ZIP already downloaded.

## Request organizer access

Use the [staff access request instructions](../SUPPORT.md#staff-access-requests). Request authorization, not a public passcode. Maintainers should verify the person through an established private organizer channel before sharing documents or repository access.

## Repository access

Source and tests contain challenge answers. The repository is organizer material. Removing current guides does not remove old commits or downloads. See [documentation handling](../DOCUMENTATION.md). Participant access normally means the app URL and Player Guide, not GitHub source access.
