# Help and developer contact

Read the pinned [Start here discussion](https://github.com/test3457890/CTFcosmolog/discussions/1) for downloads, VM setup, and access guidance.

Recommended student environment: Parrot Security OS with Docker and preinstalled analysis tools. Kali Linux with the same toolkit is the alternative.

## Setup questions

Use [GitHub Discussions](https://github.com/test3457890/CTFcosmolog/discussions) for general setup questions, supported workflows, and feature ideas. If Discussions is unavailable, use the [setup-help issue form](https://github.com/test3457890/CTFcosmolog/issues/new?template=setup-help.yml).

Include your OS/distribution, VM or host layout, Docker/Compose versions, the command attempted, expected behavior, and a short sanitized error. Say whether the app opens inside the VM and whether the issue affects the host browser only.

## Bug reports

Use the [bug report form](https://github.com/test3457890/CTFcosmolog/issues/new?template=bug-report.yml). Reproduce a problem in a fresh practice session where possible. Do not restart an active event without recording progress and coordinating with its organizer.

Do not post challenge flags, solution steps, staff passwords, vault files, unlock-key files, GitHub tokens, personal data, or screenshots/logs exposing those details. A public Issue or Discussion is not a private messaging channel. A local reset log can also reveal answers; review attachments before sending.

## Staff access requests

The maintainer shown on this repository is the contact point. Ask to be connected with the authorized organizer through an established private channel. Do not publish a passphrase or ask another person to publish one in GitHub comments.

Maintainers should verify identity and event role privately before providing the staff package or source access. Send the encrypted vault and unlock key separately. The repository does not collect staff passwords or provide an automated passcode service. No private contact address is published here unless the maintainer chooses to add one.

## During a competition

Use the event organizer's assigned help channel first. GitHub support does not imply a response time during a live event. Keep challenge-specific findings in your team notes or the organizer's approved private channel.
